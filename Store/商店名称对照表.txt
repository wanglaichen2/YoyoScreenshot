悠悠截图 — 商店显示名称对照表
================================

用途：填写 Partner Center「商店列表 → 产品名称」时对照使用。
前提：须在「悠悠截图」同一产品下「管理应用名称」中预留名称（勿建成第二个应用）。

命名原则
--------
- 「悠悠」为品牌，拉丁字母统一用 Yoyo；日/韩/中文圈保留本土写法。
- 「截图」按各语言习惯翻译（Screenshot / Capture / 스크린샷 等）。
- 商店「产品名称」只能选已预留的名字 → 下表每个不同的名称都要先预留一次。
- 安装后「开始菜单」名称：由 Pack\msix\localized_names.json 打进 MSIX（MakePri），
  随 Windows 显示语言切换；改名后需重新 pack_msix.bat 并上架新版本。

二、与程序内标题（AppTitle）对照（供参考）
----------------------------------------
安装后开始菜单/窗口标题来自语言包 AppTitle，不等于商店「产品名称」。
当前 Lang\*.lng：

| 语言代码 | 程序内 AppTitle           |
|----------|---------------------------|
| zh-CN    | 悠悠截图                  |
| zh-TW    | 悠悠截圖                  |
| ja-JP    | 悠悠スクリーンショット    |
| 其余     | YouYou Screenshot         |

注意：程序内多数语言仍是「YouYou Screenshot」，与商店推荐的「Yoyo …」拼写不同。
若希望安装后名称与商店一致，需另行改 Lang\*.lng 的 AppTitle。


三、Partner Center 操作步骤（摘要）
----------------------------------
1. 打开产品「悠悠截图」（不要打开误建的第二个应用）
2. 产品管理 → 管理应用名称 → 按上方「需预留的名称清单」逐个预留
3. 提交 / 商店列表 → 点开每种语言
4. 「产品名称」下拉按第一节表格选择对应本地化名
5. 保存并随提交一起发布

若某语言下拉看不到目标名称：
→ 该名称尚未挂在本产品「管理应用名称」下（或预留到了另一个空应用），
  需释放后回到本产品重新「预留更多名称」。
