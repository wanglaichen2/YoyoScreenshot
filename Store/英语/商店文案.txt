============================================================
1. Description
============================================================

Yoyo Screenshot is a lightweight, easy-to-use screenshot tool for Windows. It supports region capture and full-screen capture, lets you annotate while capturing (pen, rectangle, arrow, and more), and provides history thumbnail management: preview, copy, pin-to-screen, and delete. The app can stay in the system tray; closing the window does not quit the app, so you can capture anytime with hotkeys.

Ideal for office work, teaching demos, bug reports, and sharing images in chat. Screenshots are saved locally—no account sign-in required. Ready to use out of the box.

============================================================
3. Product features
============================================================

- Region capture: drag to select any screen area
- Full-screen capture: capture the current screen in one click
- Annotation tools: pen, rectangle, arrow, and more—annotate while capturing
- Re-edit: reopen existing screenshots to annotate and save
- History management: thumbnail list with preview, copy to clipboard, pin-to-screen, and delete
- Tray residency: runs in the background, ready anytime
- Global hotkeys: Ctrl+Alt+I / Ctrl+Alt+Shift+I
- Local storage: files are written to the shots folder under the app directory; data stays on your device
- Lightweight install: MSIX install for Windows 10/11 desktop devices (x64)
